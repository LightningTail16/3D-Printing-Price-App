# 3D Printing Price App

A simple web app that calculates a suggested selling price for a 3D print based on:

- Filament used (grams)
- Filament cost per kg
- Print time (hours)
- Hourly machine/electricity cost
- Profit margin

## Run locally

Open `index.html` in your browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
